# Vinheria Agnello — Checkpoint 02

## Sobre o projeto

O Checkpoint 02 da disciplina de Desenvolvimento Web consiste no desenvolvimento de um sistema de cadastro e avaliação de estoque de vinhos para a Vinheria Agnello.

O sistema permite cadastrar vários vinhos, informar seu nome, tipo, safra e quantidade em estoque, classificar os vinhos de acordo com o ano da safra e identificar produtos com estoque baixo. Ao final, apresenta um resumo dos cadastros realizados, dos vinhos com estoque baixo e do vinho com a safra mais antiga.

O projeto foi desenvolvido em HTML, CSS e JavaScript, utilizando funções, validação de dados, escopo de variáveis e laços de repetição.
